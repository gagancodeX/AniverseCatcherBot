# Third-party reference

Luna Run's independently authored WebGL renderer takes visual and architectural inspiration from:

- Repository: https://github.com/adhithyaarun/subway_surfers
- Description: a WebGL version of Subway Surfers.
- The reference repository is distributed under the MIT License.

The renderer in \`luna-run-3d.js\` is newly written for Luna GameZone and does not copy the reference repository's source files or bundled textures.
